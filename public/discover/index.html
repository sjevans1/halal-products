What do the listing labels mean? ＋

Source listed: a public institution or directory mentions this location. Tayyib has not confirmed it personally.

Self-declared: the owner describes a halal offering, without independently verified evidence.

Certified: reserved for a specific valid certificate and scope checked with the issuing body. No seeded entries currently carry this status.

Pending: submitted but not approved for public display. Pending submissions never appear in the public directory.
